# 试验用火焰密度纹理

`fire-density.png` 是为 Blender VFX Studio 原创生成的灰度密度图，使用 OpenAI 图像生成工具制作。没有输入参考作品的图片，也没有复制教程纹理。保留生成 PNG 的原始字节，1254×1254 RGB；黑色表示空处，亮灰至白色供原生材质映射火焰覆盖和热度。

SHA-256：`e8a42b39c31a9a57139dea6225d2a469bb20cd077fcfeebf4e8049b1e96a09df`。

生成要求聚焦于：不对称 S 形主体、卷曲分叉、内部热流、大小分明的破口与少量离散火丝；纯黑背景，无发光后期、场景、文字或图集排版。这是项目试验资产，尚未进入内置效果或安装包。火焰色彩、透明边缘、流动与退场由 Blender 节点处理，原图未做二次像素编辑。
