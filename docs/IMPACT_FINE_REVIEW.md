# Impact Burst：细喷射的方向与浅背景边界

[#106](https://github.com/mumu-lhl/blender-vfx-studio/issues/106) 接续气流主体重做，处理四条细喷射在远景中像细锥线的问题。原宽度曲线的最宽处在路径前四分之一，白色也靠近根部，离开的前端很细。新曲线把较宽的头部移到约七成位置，根部收紧；数量、路径和发光强度保持原样。

主层的 Geometry Nodes 中增加 `Fine Ejection Width` Value 节点，默认 1.6。它只缩放细喷射截面，不改变三团主体或两条卷流；控制器 Size 仍调整整个主层。Shader Nodes 将细喷射分为彩色头部、少量浅色内芯和跟随控制器颜色的深色边界。完整效果保存为 `.blend` 时保留这些节点，通用 Burst 参数 JSON 不保存私有造型。

实际读取第一轮 Cycles 近白 AgX 远景后发现，较白的头部融入背景，而峰值前的噪声已切碎轮廓。第二轮减少浅色混合、扩宽深色边界，并让早期细喷射保留更完整的表面。已按同相机比较修改前后 5/7/9 帧，前两条主要喷射在峰值更明确，7 帧后仍快速碎裂；较弱的其他方向和余烬尚未全部解决。

当前 11 项局部 Blender 测试与无插件重开通过。新增测试实际比较修改宽度前后的求值几何：仅细喷射变化，主体和卷流保持一致，保存完整资产后结果仍相同。Low 仍最高 824 顶点、四个显示对象和四个材质。最终检查范围见下节；测试不代替艺术判断，没有实时视频、真实角色或设备帧率结论。
