# Stylized Fire：角色施法与原生火焰

这套效果使用三团不等高的外焰、两团较小的内焰和持续上升的余烬。几何节点让宽窄起伏向上移动，并扰动火舌；材质用红、橙、黄热色与较暗边缘区分内外，断燃时火面破开并抬升。主焰持续 48 帧，余烬晚四帧结束，完整资产为 52 帧。它不需要贴图、模拟缓存或插件参与播放。

首轮实际图像中，火舌像悬空的火滴，白黄色内芯偏大。生成器因此改为更宽且连贯的底部、较小的内焰。修改前后的同帧图已读取，修正版的燃烧底部更稳定，主体仍保留侧向间隙。这些改动进入真实网格与节点，未增加预览辉光。

Width、Noise Scale、Strength、Dissolve 和 Fade 可在侧栏编辑；主层自定义属性 Fire Height、Fire Flow Speed、Fire Curl 控制高度、上卷和形变。颜色参数乘到材质的热色色带上；要改变整套热色顺序，可编辑 Painted Red Orange Yellow 色带。Low / Medium / High 改变火面采样与余烬生成率，属于同一种效果。手动节点和完整编排应使用 Save Complete Effect 保存。

四项局部检查覆盖原生时间、实际参数、质量差异和完整资产独立性；二十项示例检查、十二文件实际包通过。无插件新进程按 60、25、36 跳帧，高清像素一致，第 70 帧清空并正常退出。已发布版本仍为 0.22.2；火焰等待烟尘依赖完成后合并，不提前计入 main 的完整库数量。

## 实测成本

本地 CPU 配额 2，Blender 两线程，Mesa 25.0.7 llvmpipe；CI 为 Ubuntu、两线程、Mesa 25.2.8 llvmpipe。比较同一保存场景，只排除 VFX 集合。每种状态丢弃三轮预热求值后测量 27 个样本，渲染先预热两次再交替比较三组相同帧。

| 测量 | 无 VFX | 有 VFX |
| --- | ---: | ---: |
| 本地求值中位数 | 0.621 ms | 3.221 ms |
| 本地求值 p95 | 0.930 ms | 3.369 ms |
| CI 求值中位数 | 0.432 ms | 2.187 ms |
| CI 第 25 帧渲染 | 11.583 s | 15.373 s |
| CI 第 36 帧渲染 | 11.491 s | 15.219 s |
| CI 第 60 帧渲染 | 11.526 s | 14.160 s |

本地配对渲染分别为 13.836/20.093、15.454/21.470、15.191/20.275 秒（无／有 VFX）。这些是后台求值与渲染墙钟时间，不是视口 FPS。三个配对样本不足以报告稳定渲染 p95；低顶点数也不能代表材质渲染便宜。
