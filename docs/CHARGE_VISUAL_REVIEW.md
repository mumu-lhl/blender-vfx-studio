# Energy Charge：淡出与汇聚

0.22.2 修复 [#76](https://github.com/mumu-lhl/blender-vfx-studio/issues/76)。旧入门资产的两层环 Fade=0.35，球壳 Fade=0；第 48 帧仍保留明显亮轮廓，第 49 帧生命周期结束时整体消失。修复把这三层的现有 Fade 参数改为 1，48 帧时长、层数、粒子预算和发光强度不变。

软件 Eevee 的 16 samples 实图还显示明显的透明颗粒，因此新建充能资产的三个私有材质改用 Blended。Cycles 与 Eevee 的主体和末段已分别在无插件进程重渲染，所有 PNG 像素通道与原图一致。普通 Ring、Shield 生成器及旧完整资产的参数、材质保持原样；实际 v0.22.0 示例载入并复制后仍保留旧值。

实际读取了 Cycles、软件 Eevee、亮背景 Cycles 的第 4、22、42、48、49 帧 960×540 PNG，并对比旧版末帧。环和球壳在后段逐渐变暗，Eevee 的连续轮廓比原来的颗粒透明更稳定，末帧只有很淡的残留，结束帧清空。回归检查要求第 48 帧的像素 RGB 总量低于第 22 帧的 20%，并确认几何直到生命周期结束才移除；旧值约为 94%，未达到该标准。

预览使用相同的相机和背景，不加辉光。16:9 画面使用 7.2 的相机可见宽度，避免直接沿用正方形缩略图构图而裁掉地面环。`--legacy` 只恢复旧 Fade 与透明模式，用于同条件对照，不是旧资产迁移。

```sh
blender -b --factory-startup --disable-autoexec --python-exit-code 1 --python tools/charge_preview.py -- --legacy
blender -b --factory-startup --disable-autoexec --python-exit-code 1 --python tools/charge_preview.py
blender -b --factory-startup --disable-autoexec --python-exit-code 1 --python tools/charge_preview.py -- --engine BLENDER_EEVEE
blender -b --factory-startup --disable-autoexec --python-exit-code 1 --python tools/charge_preview.py -- --light
```

Linux 无 GPU 时可加 `LIBGL_ALWAYS_SOFTWARE=1 EGL_PLATFORM=surfaceless`。结果在 `work/visual-charge/`，含五帧 PNG 和原生场景；CI 附件名为 `energy-charge-visual-review`。末段淡出修复已在 PR #77 合并并通过三平台 CI；0.22.2 尚未发布。

随后 #79 改进新建入门资产的视觉主次。旧版外散圆粒改为从半径 1.4 处向中心移动；Spawn Radius 控制起点、Velocity 控制汇聚速度，剩余距离最低为 0，因此调高速度不会穿过中心再向外散出。出生时间、独立寿命、随机种子和槽位复用仍使用原来的原生 Emitter。默认发射率与存活槽数没有增加，重算任意帧不依赖之前的状态。

一个地面环改为倾斜轨道，用原生驱动绕中心旋转；另一个地面环降低亮度。球壳收紧到 0.65，私有材质保留噪声、透明与淡出，加入深色主体到青色边缘的渐变和前 30% 时间的显现。第一轮单纯降低双环亮度仍缺少焦点，浅背景透明球壳也很弱，因此进行了这些调整，没有提高发光强度或添加合成辉光。

预览现在生成第 4、10、16、22、28、34、42、48、49 帧。它们展示出现、汇聚、轨道转动和退场；静图检查不能代替未采样时刻或实时节奏检查。低质量球壳与环仍能看到多边形轮廓，0.22.2 的粒子仍是小圆粒，尚不称为完整的高品质角色蓄力方案。后续需结合真实动作改善粒子形状和蓄力到释放的衔接。

改变只作用于新生成的 Energy Charge 完整资产；普通 Emitter 的运动仍向外。自定义汇聚节点、渐变与轨道驱动随完整 `.blend` 保存、复制和载入。单层参数预设只保存参数，不能保存这些手动编排的节点；复用该造型应使用完整效果保存。`--legacy` 仅恢复旧 Fade 和透明模式，用于检查突切，不会恢复整个旧版造型。

本轮实际查看了 Cycles 暗背景的全部九帧、软件 Eevee 暗背景的第 4、16、22、42、48、49 帧，以及两种引擎亮背景的出现、中段和退场实图。球壳在中段成为主轮廓，轨道由正面转为侧面再转回；末段整体变暗，49 帧清空。亮背景的深色主体比第一轮透明青色轮廓更清楚，但浅蓝细线和微粒仍偏弱。没有把九帧检查写成实时观看。

本地五项入门库测试和原生重开通过，覆盖汇聚距离、抵达中心后的停止、重复跳帧、普通 Emitter 仍向外、实例独立、预算与淡出。最终 Cycles / Eevee 场景在无插件进程重渲染第 22、48 帧，PNG 所有通道与原图一致。三平台完整检查以本轮 PR 的 CI 结果为准。

## 0.22.3 候选：尖形汇聚微粒

[#85](https://github.com/mumu-lhl/blender-vfx-studio/issues/85) 把新完整资产的圆点替换成低面数尖形微粒。私有网格节点按径向朝向中心排列，横向窄、纵向长；私有材质由暗尾渐变到青色前端，Size 仍同时缩放长度与宽度。默认比例可在原生节点 Mote Proportions 中编辑，外侧发射位置、汇聚速度、发射率、寿命、种子和发光强度不变。没有新增通用模块参数或资产版本；普通 Emitter 和旧完整资产继续保留原网格。

实际查看了 Cycles 暗背景的第 4、22、42、48 帧，软件 Eevee 暗背景的第 4、22、42、48、49 帧，以及 Eevee 亮背景的第 4、22、42、48 帧，并对比保留的圆粒峰值。尖形轮廓比圆点更能显示指向中心的方向，未盖过球壳焦点；末段缩小，亮背景的细小尾粒仍弱。静帧不证明连续运动或释放衔接已重新验收，后续仍需复用衔接场景检查。

六项入门库测试覆盖单个微粒的径向长宽比、每粒几何少于原 LOW 圆粒、Size 缩放、汇聚停止、跳帧与淡出，完整示例 ZIP 也通过无插件重开。Cycles、Eevee 暗/亮背景的第 22、48 帧已在无插件新进程重渲染，所有像素通道一致。0.22.3 尚未发布，三平台完整结果以关联 PR 为准。
