# Energy Charge：造型与运动重设计

[#89](https://github.com/mumu-lhl/blender-vfx-studio/issues/89) / [PR #90](https://github.com/mumu-lhl/blender-vfx-studio/pull/90) 跟踪这轮未发布的重设计。用户指出原来的半透明球壳、细环和小粒子缺少聚能感；先前的功能测试与局部修补不构成整体艺术验收。0.22.2 下载包保持原样，普通 Shield、Ring、Emitter 和已有完整资产也不被重建。

## 原因与实际修改

原核心只等比缩放 UV Sphere，环保留规则闭合圆，粒子按速度乘时间直线移动。Fresnel、噪声和透明度渐变主要改变表面，无法建立收束的形体和节奏。修改发生在 `tools/build_examples.py` 与 `tools/charge_design.py` 的真实入门资产生成器中，仍保留四个控制层。

- 核心由厚实主瓣、两片较低的辅助瓣和内部亮核组成。形体随进度收紧、局部鼓胀和卷动；主瓣、辅助瓣的比例与朝向不同。材质区分深蓝外缘、青色中间层、亮白正面和盘旋裂隙。正面明暗根据表面朝向绘制，属于风格化表面着色，不是体积散射。
- 三条三维曲带向内盘卷。宽度、弯曲和移动速度分别变化；材质按路径与横向坐标裁出两端收尖的移动段，段间不保留整条半透明底带，减少浅背景的灰色腰带感。
- 地面层是五条长度、宽度不同的辅助收束形状，随蓄力缩向中心，保持较低视觉权重。
- 较大的尖形微粒沿弯曲轨迹绕行并加速汇聚，朝向跟随实际轨迹，抵达中心后停止。默认发射率从 18 降到 14，存活槽从 15 降到 12，发光强度从 3 降到 2。

共享的 0–1 进度控制整套节奏。前 18% 长出，12%–80% 收紧体块，82% 后表面侵蚀，84% 后几何快速塌缩，核心约在 94% 完成退场，辅助层随后清场。默认 48 帧、24 fps；Duration 或 Speed 会缩放整套节奏，任意跳帧不依赖之前播放过什么。

## 看图发现的问题与迭代

实际比较了旧发布资产与多轮 960×540 PNG。早期候选过长，随后又像硬质叶片：纵向缩放从 0.6 增到 1.2，同时横向缩小 32%，主动把核心拉薄。现在增宽、缩短主瓣，降低辅助瓣和卷曲幅度，纵向仅从 0.85 增到 0.9，流带高度也随之降低。实际读取出现、中段与峰值图，主体更紧凑，亮白核心与暗边的主次更清楚；发光强度仍为 1.2。

Eevee 曾把后方亮核画在外壳前面，形成完整白色椭圆。核心改用深度正确的 Dithered 镂空后，又在退场出现整片颗粒：原因是 Alpha 随释放降低。现在默认用空间侵蚀让外壳先碎、内核后碎，保留部分保持不透明，Fade 控制释放时的侵蚀量。实际重看浅背景释放相邻帧，大面积抖动减少。主动降低 Opacity 仍可能在低采样 Eevee 出现抖动透明。

隔帧检查还发现 Cycles 末段黑点：重叠透明表面耗尽默认的八次穿透预算。原生场景第 46 帧出现 26 个近黑像素，提高穿透次数或隐藏核心后均为零；这两项只用于诊断。真实生成器现通过几何节点跳过完全隐藏或已经塌缩的核心表面，保留可编辑原网格，不提高用户场景的穿透预算。浅背景回归也验证 Opacity=0 / Dissolve=1 时，核心与其余层交叠仍不会挡住背景；这个问题在原来的黑背景测试中无法看出。

`9745ccc` 的原生场景还实际读取了正面、侧面、俯视和双倍远景的浅背景峰值图。之后去掉流带段间底带，并比较 Cycles 暗背景与 Eevee 浅背景的 13、22、31、37 帧，移动段的颜色与间隔更清楚。最新隔帧、衔接及原生重开范围在 #89 / PR #90 记录；图像渲染成功与测试通过不会自动批准艺术品质。

本轮目标是有明确焦点、可读收束方向和分层退场的苍蓝电浆蓄力。仍需真实角色动作镜头与实际低配置视口检验，不能称为成熟商业游戏品质。当前通过静态抽帧分析变化，没有实时观看视频。新缩略图和高清检查都不添加额外辉光。

## 编辑、兼容与预算

四层使用原生网格、节点、材质和驱动，无外部纹理、缓存或逐帧 Python。颜色、尺寸、时间及各层适用的参数保留在侧栏；只显示编排实际使用的参数，原球体的 IOR / Rim Power、微粒的 Gravity 等不适用控制隐藏。复杂形体和阶段曲线可在命名的 Geometry Nodes / Shader Nodes 中编辑。

请用 Save Complete Effect 保存这些节点和显示设置。单层参数 JSON 只保存基础模块参数，重建时不能恢复这套编排。实际发布的 0.22.2 完整资产及其副本已作为兼容对照，无插件重开后仍保留原节点和圆形粒子。

默认最高约 826 顶点，上限测试为 900；四个显示对象、四个材质、12 个粒子槽。云端对旧资产与 `68adba4` 原生场景各预热 48 帧，再顺序测量三轮几何/驱动求值：旧版最多 422 顶点，中位约 1.05 ms；候选最多 826 顶点，中位约 2.31 ms、95% 样本不超过 2.85 ms。这不包含材质绘制，也不是低配置电脑的视口帧率承诺。

## 重建与核对

```sh
blender -b --factory-startup --disable-autoexec --python-exit-code 1 --python tools/charge_preview.py -- --sampled
LIBGL_ALWAYS_SOFTWARE=1 EGL_PLATFORM=surfaceless blender -b --factory-startup --disable-autoexec --python-exit-code 1 --python tools/charge_preview.py -- --engine BLENDER_EEVEE --light --sampled
blender -b --factory-startup --disable-autoexec --python-exit-code 1 --python tools/charge_preview.py -- --baseline-asset path/to/old-energy-charge.blend
```

固定相机与 960×540 分辨率。`--sampled` 隔一帧渲染并保留额外检查帧；小范围比较可改用 `--frames 13 22 31 37`，二者互斥。结果在 `work/visual-charge/`，包括 PNG、停在第 31 帧的原生场景和 `render-settings.json`。完成记录包含引擎、帧列表及生成脚本哈希，渲染与保存成功后才写入；若源码中途改变则拒绝写入。目录可能遗留旧 PNG，应只使用本次记录列出的帧。

`--baseline-asset` 读取真正旧完整资产；旧 `--legacy` 只恢复 Fade 和透明模式，不能作为完整旧外观对照。无插件重开检查会重渲染出现、中段、压缩与退场帧，逐像素比较保存前后结果，并检查生命周期结束后没有特效网格。
