# Energy Charge：造型与运动重设计

当前工作由 [#89](https://github.com/mumu-lhl/blender-vfx-studio/issues/89) 跟踪，尚未发布。用户复核认为原来的球壳、细环和小粒子距离成熟二次元游戏特效仍远；先前的淡出、尖粒和环显现只解决局部问题，不构成整体艺术验收。0.22.2 下载包保持原样。

## 为什么原效果显得单薄

原核心的几何节点只等比缩放 UV Sphere，环始终按固定半径闭合，粒子 Travel 使用速度乘时间的直线距离。Fresnel、噪声、残影和 Lifetime Fade 主要改变表面颜色与透明度，既没有重组主体轮廓，也没有让空间分布逐渐收束。小粒子和透明青色在浅背景上尤其弱。

这轮修改实际入门库生成器，保留四个控制层，重新安排其作用。

- 核心由三片不等高、偏斜的能量瓣和一个内部亮核组成。几何随进度收窄、拉长、加速扭转，并以四维噪声改变轮廓；材质区分深色外壳、沿形体盘旋的裂隙和内部亮部。
- 三条带状流从外部向内盘卷。宽度、弯曲与运动亮脉冲各自变化，前端用几何连续推进并收尖，避免只旋转固定圆环或逐段删除造成平切口。
- 地面层是五条长度和宽度不同的收束形状，保持辅助权重，随蓄力缩向中心。
- 微粒沿弯曲轨迹先绕行再加速内收，朝向按轨迹切线计算，出生时逐渐长出，抵达中心后停止。尺寸加大以读出方向，默认发射率从 18 降为 14，存活槽从 15 降为 12；发光强度也从 3 降为 2。

统一 Progress 控制起势、收束、压缩和释放。核心在寿命前 18% 长出，12%–80% 逐渐收紧并拉长；82% 后材质侵蚀，84% 后形状快速塌缩。默认 48 帧、24 fps；改变组合 Duration 或 Speed 会缩放整套节奏，不依赖之前播放过哪些帧。

## 已进行的实际看图与修改

实际查看了原版、各次原型和多阶段 960×540 PNG。第一版像过长晶柱，随后改为不等高分支；第二版亮纹像塑料斑点，改为沿形体的能量通道；条带像折纸和橡胶圈，又调整了采样、宽度变化、暗边和向内移动的脉冲。增加内部亮核后，Eevee 的 Blended 将后面的亮核盖在前壳上，同背景下明显不同于 Cycles；核心改为深度正确的 Dithered 镂空，以不透明表面与孔洞为主，流带仍用 Blended。

已读取隔帧图检查从铺开到收紧、裂解的变化，并直接比较 Cycles / Eevee 的同帧和暗/亮背景。核心不再是完整球壳，流带范围逐渐变小，后段亮核与拉长轮廓成为焦点。Eevee 中原来完整白色椭圆的排序问题已改善。最终候选的看图范围、未完成检查和 CI 结果会随 PR 记录；不因测试通过就宣布艺术验收，也没有实时观看视频。

当前风格更接近苍蓝电浆与漩涡蓄力。它仍需要放入角色动作及更多镜头中判断；不能据此称为成熟商业游戏品质。浅背景中的最细地面纹和末段碎片仍弱，轮廓、节奏和层次应继续以实际画面判断。

后续对 `4ac20c9` 候选逐帧复核时，实际读取了 Cycles 暗背景的全部 30 个隔帧样本、Eevee 浅背景的 11 个关键帧，以及衔接场景的 13、25、31、33、37 帧。空间收束已经可见，但核心仍像硬质叶片，流带的连续明暗渐变像金属带。因此没有批准艺术验收，也没有关闭 #89。

针对这个问题，核心新增沿各瓣向上移动的局部鼓胀和延迟卷曲。每瓣有独立相位，越靠尖端弯曲越明显；原有轴向扭转与轮廓噪声继续保留。流带改成深边、中间色、青色窄带三个色阶，减少高光混白，并提高脉冲之间的颜色覆盖，避免浅背景透过低透明度把蓝色洗成灰色。几何数量不增加。实际查看了这一版 Eevee 浅背景的 7、22、31、37 帧：轮廓的弯曲与前后变化更明显，流带色带更清楚；它仍有薄片感，不能写成已经达到成熟游戏品质。最终隔帧检查另行记录。

`582cf97` 的 Cycles 30 个隔帧样本已全部读取，Eevee 浅背景抽查了 7、13、22、31、37、42、46 帧。卷动带来了形变，也暴露出新问题：较窄内核与外壳用了同样大的尖端位移，23–41 帧的部分画面出现向外刺出的白尖。随后将内核的尖端卷曲减到外层的 15%；实际重新读取 Cycles 的 23、31、41 帧，白尖减少。这个修正只限制内核形变，不提高发光，也不改变外部流带。Eevee 低采样下的退场抖动和主体薄片感仍是明确的后续问题。

这轮九项入门库行为测试通过。`582cf97` 的两组原生场景在不导入插件的新进程中重渲染 4、7、22、37、48 帧，PNG 全通道一致，第 49 帧没有特效网格。该结果证明保存后的原生播放，不能证明视觉品质。CI 同时保留浅背景 Eevee 的隔帧图和实际 examples ZIP，便于检查动画变化与编辑节点；以对应提交的 Actions 结果为准。

## 编辑、兼容与预算

四层仍是 Blender 原生网格、材质和驱动，无外部纹理、缓存或逐帧 Python。核心、流带、地面和粒子共同保留颜色、尺寸、时间及各自适用的参数。侧栏只显示该编排实际使用的参数；原球体的 IOR / Rim Power、粒子的 Gravity 等不适用控制不再显示。复杂形体和阶段曲线在命名的 Geometry Nodes / Shader Nodes 中编辑。

使用 Save Complete Effect 保存这些节点与显示设置。单层参数 JSON 仍只保存基础模块参数，重建时不会恢复本编排。普通 Shield、Ring、Emitter 与旧完整资产不被重建；已发布的旧包作为实际兼容与视觉对照。

默认几何上限为 900 顶点，设计最大值约 826，仍为四个显示对象、四个材质、12 个粒子槽。较旧原型增加了必要的形体采样和内部亮核，预算变化公开记录，不宣称零成本。后台求值与软件 Eevee 不能证明集成显卡视口帧率。核心默认以不透明和镂空为主；主动降低 Opacity 后，低采样 Eevee 可能出现抖动颗粒。

## 重建与对照

```sh
blender -b --factory-startup --disable-autoexec --python-exit-code 1 --python tools/charge_preview.py -- --sampled
LIBGL_ALWAYS_SOFTWARE=1 EGL_PLATFORM=surfaceless blender -b --factory-startup --disable-autoexec --python-exit-code 1 --python tools/charge_preview.py -- --engine BLENDER_EEVEE --light --sampled
blender -b --factory-startup --disable-autoexec --python-exit-code 1 --python tools/charge_preview.py -- --baseline-asset path/to/old-energy-charge.blend
```

固定相机和 960×540 分辨率，不加辉光；`--sampled` 每隔一帧渲染并保留额外检查帧。结果在 `work/visual-charge/`，包括 PNG、停在第 31 帧的原生场景和 `render-settings.json`。记录包含引擎、帧列表和生成脚本哈希，全部渲染与保存成功后才写入，不自动批准视觉品质。`--baseline-asset` 读取真实旧资产而不是用新节点伪造旧外观；旧 `--legacy` 只恢复 Fade 和透明模式，不是完整旧版对照。

小范围迭代可用 `--frames 13 22 31 37` 只重渲染指定帧；它与 `--sampled` 互斥。目录可能保留上次的其他 PNG，应以本次完成记录的帧列表和脚本哈希判断图像来源。

保存重开检查渲染出现、中段、压缩和退场帧。实际源码、模型和安装仍可从全新克隆恢复；旧版本具体技术检查保留在 [0.22.2 文档](https://github.com/mumu-lhl/blender-vfx-studio/blob/v0.22.2/docs/CHARGE_VISUAL_REVIEW.md)。
