# Energy Charge：进流轮廓与移动亮前沿

[#110](https://github.com/mumu-lhl/blender-vfx-studio/issues/110) 接续充能压缩重做，处理核心仍像连续弯叶、汇聚方向不明确的问题。原几何已沿路径推动膨胀的能量团，但一层亮面主要跟随固定的内侧位置；辅助路径的截面也始终保留较多面积。

候选将两个主体路径改为更开放、向中心收束的钩形，减少绕行角度，并增加截面深度。主体保留较细的连续引导线，四条辅助流在能量团之间收至零；两类路径的头部最大截面保持相同，中心小内核不变。原生几何节点提供 Main Intake Guide Width、Auxiliary Guide Width 和 Auxiliary Packet Width 控制，完整 `.blend` 保存这些编辑。

几何膨胀与材质窄亮前沿共用同一个路径相位。亮前沿随能量团向内移动，不再固定在路径内端；亮色只占前沿的一条窄带，整体发光强度和粒子数量不增加。仍为四层、12 个粒子槽、Low 最高 894 顶点，旧完整资产与普通模块不重建。

已实际读取多轮 Cycles 的 13/15/17/31/33/35/42 帧，并与旧版同镜头比较。仅收细辅助线的首轮改动不够明显，因此继续修改主体路径和亮部位置。最新候选仍有弯曲带状结构，不能据此宣布整体艺术目标完成；最终 Eevee、浅背景、远景、其他视角和完整连段正在继续检查。

当前 13 项入门库 Blender 测试和无插件重开通过。新增检查验证辅助宽度控制不移动两条主体与内核，保存完整资产后状态一致；几何和颜色在统一变速后也保持一致。测试用于保证行为，不替代看图。整体 #89 保持开放，0.22.3 不发布，没有实时播放、真实角色或实际设备帧率验收。

补充回归：浅背景看图发现零宽度段仍留下细线。实际面积检查复现了问题：扭转高度和轮廓扰动仍读取调整截面前的坐标，让本应重合的顶点再次分离。现统一读取调整后的坐标；关闭辅助头部与引导线时，其表面积降至浮点误差范围，13 项测试通过。


## 编辑这套进流

在 Outliner 展开 Energy Charge 组合，选择核心网格 `VFX • Compressed Flame Core`，再打开 Geometry Nodes。Main Intake Guide Width 调整主体上能量团之间的细连接；Auxiliary Guide Width 调整四条辅助流的连接，默认 0 表示保留分离的能量团。Auxiliary Packet Width 调整辅助头部的最大宽度，改变连接宽度不会同时放大头部。

例如将 Auxiliary Packet Width 和 Auxiliary Guide Width 都设为 0，可只看主体与内核；恢复非零头部宽度即可恢复辅助流。这些操作不删除基础网格。颜色、开始帧、时长与速度仍在原控制器上编辑。要保留这套私有节点及其修改，请保存整个组合为 Complete Effect；通用 Shield 参数 JSON 不保存进流造型。

前后对照还发现，过早收紧主体路径的径向分布会让蓄力早段也偏小。候选已恢复原来的径向范围和起伏高度，保留开放转向与移动前沿，以保留后段压缩的体量差；13 项测试再次通过。
