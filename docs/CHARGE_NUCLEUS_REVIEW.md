# Energy Charge：把积蓄过程留给内核

[#114](https://github.com/mumu-lhl/blender-vfx-studio/issues/114) 接续外层汇聚路径改进。旧内核很早就呈现近白色，后段虽然外层收紧，中心的积蓄变化却较小。问题同时来自几何尺寸和材质时间：内核一直保留较完整的体量，亮色混合从 0.55 起步，较早接近峰值。

新方案在外层压缩的同一时间窗口内，让内核从较小的蓝色体积增长为更饱满的亮核。颜色的集中延后，内核在释放窗口才交出亮色；外部流动前沿的时间不变。这样由外围收拢与中央积蓄共同表现蓄力，不增加发光强度、粒子、对象或顶点。

初步已实际查看 Cycles 暗背景与浅背景的 13/22/37 帧前后对照。早段近白面积减少，后段亮核更集中；早段内核可能被进流遮住，远景焦点和连续变化仍需检查。初始候选在 Eevee 远景中蓝核偏小，因此将初始/蓄满尺寸从 0.5/1.15 调整为 0.65/1.35；已实际读取调整后的 Eevee 浅背景和 AgX 远景 13/22/37 帧，初期蓝核较清楚，仍存在遮挡和远景细层偏弱。完整多视角与连续复核尚未完成，不作整体艺术验收。

16 项 Blender 入门库测试通过。新增行为检查验证内核在外围压缩时增长，且原生尺寸控制能改变早段体量、设为 0 时主体与轮廓扰动同时收零；原有变速、保存载入、零宽度和 Low 预算检查保留。最高仍为 894 顶点、四个显示对象、12 个粒子槽。旧完整资产不重建，#89 保持开放，0.22.3 不发布。

在核心 `VFX • Compressed Flame Core` 的 Geometry Nodes 中，Nucleus Seed Size 控制初始尺寸，默认 0.65；Nucleus Stored Size 控制积蓄后的尺寸，默认 1.35。两者是相对现有内核的倍率，不改变外围路径。原控制器的颜色、发光、开始帧、时长和速度继续生效；保存 Complete Effect 保留私有节点编辑。
