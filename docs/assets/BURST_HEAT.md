# 命中热气的图集原图

`blender_vfx_studio/assets/burst_heat.png` 是本项目通过 image_gen 辅助生成的原创热量图，不是从参考游戏或教程截取的素材。灰度表示热区与冷区，透明度表示气体边缘；最终配色由 Blender 原生材质节点提供。文件随项目许可分发。

图集按四列两行排列，共八帧：点燃、快速展开、峰值、扩张、分离、残留与清场。原图及其摘要已经提交，新的 Git Clone 无需图像生成服务或联网即可构建。图像有少量透明通道量化残余，组件在生命周期结束时由几何节点清空。

源文件的尺寸、校验值和生成要求见 [记录](burst_heat.json)。这个文件是原图来源说明，不代表整个效果已通过艺术验收。纹理可在 Blender Image Editor 中编辑或替换；Geometry Nodes 和 Shader Nodes 负责朝向、深度、取帧、配色与透明度。
