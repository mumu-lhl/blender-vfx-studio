# 魔法阵准备与火焰释放

这段 108 帧、24 fps 的角色镜头使用实际 Magic Circle 和 Stylized Fire 生成器，展示准备、保持、释放和消散。它是两套既有资产的组合用途，不计作额外特效种类。

## 动作与效果

| 阶段 | 时间 | 画面职责 |
| --- | --- | --- |
| 准备／保持 | 第 1–51 帧 | 原生施法动作配逐笔印记，印记位于角色脚下 |
| 释放 | 第 52 帧开始 | 前方火焰快速长出，立体符记作为辅助 |
| 主体维持／退场 | 第 64–103 帧 | 地面印记先退出，火面随后破开、上升并变薄 |
| 恢复 | 第 104–108 帧 | 特效清空，角色保持原生站姿动画 |

角色采用固定版本 CC0 KayKit 动作和原生 NLA。释放时刻由作者安排，不是物理接触。恢复站姿使用持续循环，释放动作在最后六帧退回站姿；播放不需要 Python 回调。

## 实测成本

CI 为 Ubuntu、Blender 两线程、软件 llvmpipe；960×540、Eevee 16 samples。同一保存场景只切换 VFX 集合，各测量 27 个预热后求值样本，渲染先预热再交替比较相同帧。

| 测量 | 无特效 | 有特效 |
| --- | ---: | ---: |
| 求值中位数 | 0.604 ms | 3.558 ms |
| 求值 p95 | 0.643 ms | 3.629 ms |
| 第 40 帧渲染 | 14.592 s | 26.528 s |
| 第 64 帧渲染 | 14.621 s | 41.917 s |
| 第 96 帧渲染 | 14.581 s | 28.639 s |

这些是后台求值和软件渲染墙钟时间，**不是视口 FPS**；三个渲染配对不足以报告稳定 p95。质量选择按镜头收益判断，不设统一低成本上限。

## 生成和编辑

```sh
blender -b --factory-startup --disable-autoexec --python-exit-code 1 -t 2 --python tools/spell_preview.py
```

脚本要求全新后台进程，输出在 `work/spell-review/light-near/`。`--dark`、`--far` 生成对照，`--sequence` 渲染全部 108 帧，`--frames 40 64 96` 可指定阶段。编辑两个 **Spell** 组合控制器调整位置和时间，各层保留独立原生节点与材质；场景保存普通 NLA、关键帧和驱动器，无需插件参与播放。
