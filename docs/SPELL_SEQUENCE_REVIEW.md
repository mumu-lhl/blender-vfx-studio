# 魔法阵准备与火焰释放

这段 108 帧、24 fps 的镜头使用真实 Magic Circle 和 Stylized Fire 生成器，检查完整施法动作里的准备、释放和消散。它是两个既有资产的组合用途，不计作第九套效果。

角色采用仓库固定版本 CC0 KayKit 的 Spellcast_Raise、Spellcast_Long 和 Spellcast_Shoot。魔法阵第 1 帧开始形成；第 52 帧安排释放，前方火焰开始生长；第 73 帧魔法阵清空，第 104 帧火焰与余烬清空。这是作者安排的释放时刻，不是物理接触检测。

## 已完成与待检查

首轮浅背景第 40、52、64、96 帧已实际读取：火焰占主要面积，地面印记与升起符记作为辅助，角色上半身仍可辨认。未增加辉光或预览专用材质，也未据此宣称完整动画已经通过。

时序检查发现旧 96 帧角色夹具的站姿会在更长镜头的第 104 帧回到绑定姿态。另接站姿还会重置循环相位：第 97 帧的姿态矩阵变化约为相邻变化的六倍。生成脚本现延长原来的 NLA 循环，保留相位，并让释放动作在最后六帧退回站姿。三项行为检查及新进程无插件回放通过，覆盖准备/释放边界、完整清空、跳帧一致与恢复阶段姿态。

最终修正版的明暗背景、远景高清阶段图、完整动画隔帧、高清无插件像素比较和实测成本仍待检查。**未观看实时播放。** #151 保持开放，原八套资产不因此获得新的整体艺术结论。

## 生成与编辑

```sh
blender -b --factory-startup --disable-autoexec --python-exit-code 1 -t 2 --python tools/spell_preview.py
```

脚本要求全新后台进程，生成的 `.blend` 和检查 PNG 位于 `work/spell-review/light-near/`。使用 `--dark` 或 `--far` 生成背景/距离对照，`--sequence` 渲染完整 108 帧，`--frames 40 64 96` 可只生成选定阶段。

保存场景使用原生节点、关键帧、NLA 动作条与驱动器，不需要插件参与播放。编辑两个 **Spell** 组合控制器可调整位置和时间；各层材质和节点保持独立。灯光与相机沿用中性角色舞台，实际背景与原始材质均保留。
