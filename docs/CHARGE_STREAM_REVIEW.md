# Energy Charge：重做束流与向内运动

[#116](https://github.com/mumu-lhl/blender-vfx-studio/issues/116) 继续处理主体像弯叶、外层像菱形片段的问题。旧主体的完整椭圆截面、宽度峰值和连续连接容易形成单片叶状轮廓；外层材质的前后边缘接近对称，整体旋转又盖过了向内运动。

本轮将两个主体各拆成前沿错开的双束，保留有厚度的截面，增加沿路径的采样。辅助流从四条减为两条，将顶点集中给主体。轮廓不等、局部转向和主次亮度分别处理，主体之间留下真实空隙；四个显示对象、12 个粒子槽与 Low 最高 894 顶点预算保持不变，内核积蓄节奏不变。

核心的材质细节使用沿路径的坐标，与几何前沿共用向内相位；明暗通道和边缘侵蚀随能量团移动。重用原有噪声节点，没有再叠加一层核心噪声。外层改成长尾、短尖头，减慢整体绕行，并降低宽度，避免辅助流夺走中心焦点。流段密度和行进距离分别控制，修改密度时保持行进速度。

已实际比较多轮 Cycles / Eevee 暗、浅背景关键帧。平面交叉流带增加了纸片感，三条流带分摊顶点后出现方折，均未选用。当前有截面的双束与沿流动材质呈现出更多内部层次，但远景、侧面、出现到消散的连续变化仍需复核，不能据局部图宣布整体艺术验收。

18 项真实 Blender 入门库测试通过。新增检查按截面面积追踪能量团，确认它向核心移动；释放形变只影响内核，变速后几何仍一致；材质通道对比能改变颜色而不改变覆盖范围。原有预算、统一变速、宽度隔离、零值、保存载入和隐藏表面检查保留。普通模块与旧完整资产不重建，完整高清重开、示例 ZIP、完整连段和 CI 尚在继续验证。

原控制器继续调整颜色、尺寸、开始帧、时长、速度和循环。在核心网格的 Shader Editor 中，Intake Channel Contrast 调整内部明暗差异，Intake Fraying 调整沿流动边缘的侵蚀；外层材质的 Flow Packet Density / Inward Flow Travel 分别调整片段密度与向内行进距离，Geometry Nodes 的 Field Rotation 调整绕行。Main Intake Guide Width 现在调整每束主流中的连续连接，辅助流控制保持原用法。保存 Complete Effect 才会保留这些私有节点，通用参数 JSON 不保存它们。

整体 #89 保持开放，0.22.3 不发布。释放阶段再让内核在原位短暂收束、拉伸为亮线后退场，避免只有整体缩小。已读取 37/40/42/43/44/45 帧的 Cycles 图；默认预览与无插件重开新增 43 帧，保留出现、积蓄与退场检查。Release Pinch / Release Stretch 在核心 Geometry Nodes 中控制收束和拉伸，可同时设为 0 关闭形变。旧中间版本的渲染单独归档，新冻结源码继续完整复核。

当前没有实时播放、真实角色镜头或实际设备帧率验收。
