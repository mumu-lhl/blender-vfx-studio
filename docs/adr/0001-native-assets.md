# ADR 0001：原生资产与轻量创作层

状态：采纳。

需求包括插件停用后的播放、低配置可用、原生节点编辑、多实例独立和可靠任意帧预览。
采用 Empty 控制器的原生 ID 属性、私有节点树与 Blender 简单驱动表达式；Python 仅用于创建、复制、删除及 UI。
首个切片以原生 Mesh + Geometry Nodes + Shader Nodes 实现冲击波与能量环。

代价：驱动表达式必须属于 Blender simple expressions 子集；每实例私有节点树增加少量内存；手动删改接口可能使驱动失效。
可以接受，因为实例独立性与保留用户编辑更重要。等真实场景出现开销证据后，再优化不可变资产共享。
暂不实现 Unity VFX Graph 式编辑器，也不建立 Python 每帧粒子循环。

验证证据：5.2.2 后台测试和禁用脚本自动执行、未导入插件的新进程重开测试。
