# Dust Impact：落地烟尘与原生密度网格

这套效果把云团、地面薄尘和碎屑分开：短促碎屑先飞出，不等大的云团横向铺开、缓慢抬升，再逐渐变薄。它不发光，需要场景灯光，适合落地、踩踏和地面扰动，不代替强烈的命中爆发。

## 为什么改为密度网格

首轮半透明表面球看起来像石块，实际读图后弃用。后来把程序化体积材质放在封闭网格域上，Eevee 阶段图可用，但 Cycles 出现矩形区域；关闭阴影、替换坐标、显式透明表面和更换域缩放方式都没有消除问题。具体渲染器内部原因未确定。

最终使用 Blender 原生 **Volume Cube**：把空间划分为小格，每格保存当前帧的烟尘密度。几何节点计算团块形状、向外运动、抬升和噪声；**Set Material** 显式指定体积材质，让颜色控制真正生效。Cycles 与 Eevee 的实际对照中矩形消失。显示用的线框域只有编辑边界，不参与表面渲染；顶点数不能代表体积计算成本。

这是一套按当前帧直接计算的程序化效果，不是流体模拟，不依赖历史缓存、外部 VDB 文件或 Python 逐帧回调。

## 编辑与质量

| 控制 | 作用 |
| --- | --- |
| Width / Expansion | 团块大小与铺开距离 |
| Noise Scale / Dissolve / Fade | 内部细节、密度侵蚀与消散 |
| Dust Rise Height | 主层自定义属性中的抬升高度 |
| Dust Roll Speed | 主层自定义属性中的纹理上卷幅度 |
| Dust Density | 主层自定义属性中的光学密度 |

| 质量 | 体积采样分辨率 | 密度团 | 碎屑 |
| --- | --- | ---: | ---: |
| Low | 20×20×14 | 5 | 8 |
| Medium | 32×32×24 | 7 | 14 |
| High | 48×48×36 | 10 | 20 |

完整资产持续 32 帧，默认 Medium。三档保留主要团块与时序，改变体积精细程度、次级团块和碎屑。它们是同一种效果。自定义属性位于主层 **Object Properties → Custom Properties**；节点和密度场也可直接编辑。用 **Save Complete Effect** 保存私有造型。

## 实际检查

最终功能源码为 `5598ae90d3457350627236150aea55dadfb396f8`。本地已实际读取浅背景近景、暗背景近景、浅背景远景各十张 960×540 阶段图，以及三档真实 Cycles 嵌入预览。使用 Eevee 32 samples、AgX、无辉光；云团可辨认，前两帧与远景碎屑较弱。修正后的完整 CI 动画仍在运行，旧网格域版本的 30 张视频隔帧图不能代替最终密度网格版本的运动检查。**未观看实时播放。**

角色来自固定版本 CC0 KayKit：原地跳跃姿态配合明确设置的 0.75 米原生根位移，求值后的脚部网格检测到第 27 帧落地，烟尘从该帧触发。四项局部行为检查和新进程原生重开通过；无插件按 47、33、39 跳帧，高清像素一致，第 59 帧清空并正常退出。实际九文件包通过，八种效果整合后的完整后台套件及全新克隆十八文件构建也通过。

## 实测成本

比较同一保存镜头，只排除 VFX 集合。环境为 CPU 配额 2、Blender 两线程、Mesa 25.0.7 llvmpipe，960×540、Eevee 32 samples。求值各取 27 个预热后样本，渲染先预热两次再交替比较三组相同帧。

| 测量 | 无 VFX | 有 VFX |
| --- | ---: | ---: |
| 求值中位数 | 0.663 ms | 64.347 ms |
| 求值 p95 | 0.731 ms | 67.443 ms |
| 第 33 帧渲染 | 33.741 s | 35.795 s |
| 第 39 帧渲染 | 29.761 s | 37.703 s |
| 第 47 帧渲染 | 28.670 s | 36.892 s |

密度网格需要每帧计算，有明确的 CPU 代价；这次取舍解决了真实画面错误，同时保留体积与编辑能力。需要减少开销可选 Low，镜头需要细节时可用 High，不要求所有效果统一低成本。这些数字是后台求值和软件渲染墙钟时间，**不是视口 FPS**；三组渲染也不足以报告稳定 p95。
