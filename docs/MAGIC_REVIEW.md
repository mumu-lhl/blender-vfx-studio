# Calligraphic Magic Circle：逐笔形成与符记释放

这套效果由花瓣主印、反向转动的符文带和上升符记组成。前段逐笔形成，中段保持并缓慢转动，释放时符记升起，地面印记先退去。图案是本项目生成的曲线式网格笔画，不使用字体、贴图或模拟缓存，仍能在 Blender 中直接编辑网格、节点与各层参数。

## 编辑与复用

- **Radius / Width**：调整图案尺寸与笔画宽度。
- **颜色 / Strength**：分别设置主印、符文带和释放符记的视觉权重。
- **Noise Scale / Dissolve / Fade**：调整墨迹侵蚀和退场。
- **Sigil Spin**：各层 Object Properties → Custom Properties 中的周期转角。
- **Sigil Lift**：释放层自定义属性中的升起高度。

完整资产持续 72 帧。三档质量改变曲线采样密度，保留同一图案和时序，属于一种效果。手动节点、网格笔画和多层关系请用 **Save Complete Effect** 保存，参数 JSON 不包含这些私有造型。

## 成本与取舍

CI 使用 Ubuntu、Blender 两线程、软件 llvmpipe，960×540、Eevee 16 samples。比较同一保存场景，只排除 VFX 集合；求值各取 27 个预热后样本，渲染先预热两次再交替比较三个相同帧。

| 测量 | 无 VFX | 有 VFX |
| --- | ---: | ---: |
| 求值中位数 | 0.598 ms | 1.287 ms |
| 求值 p95 | 0.611 ms | 1.311 ms |
| 第 16 帧渲染 | 14.151 s | 26.240 s |
| 第 40 帧渲染 | 14.209 s | 27.198 s |
| 第 60 帧渲染 | 14.133 s | 28.489 s |

这是后台求值和软件渲染墙钟时间，**不是视口 FPS**；三个配对样本不足以报告稳定渲染 p95。笔画、透明层和材质需要真实渲染成本。质量取舍应服务于镜头效果，不要求全部效果达到同一个低成本目标。
