# Impact Burst：断裂压力体积

[#124](https://github.com/mumu-lhl/blender-vfx-studio/issues/124) 处理主体像实心弯管的问题。原截面封闭、弯曲较大，年轻主体的破碎阈值又低，大部分表面完整不透明；宽暖色渐变进一步强调了圆实体。

实际对比后，去掉管面没有明显改善投影，开放薄面从侧面看过薄，成对三角体又形成弯角，均未选用。当前候选保留三团体积，缩短弯曲路径，用多瓣截面改变轮廓。主截面从六点改为八点，Low 沿向从十四圈减为十二圈，最高顶点由 824 增至 860，仍在原检查的 900 上限内；四个显示对象与原粒子数量不变。

主体的破碎遮罩改用以网格自身为基准的三维坐标，让破口穿过厚度；细喷射和辅助卷流继续使用原 UV 与路径。年轻主体先形成不规则开口，再交给原有的消散控制。暖色表面由宽渐变改为较明确的色面，近根部的白色范围延伸，衔接短闪与喷流；发光强度不变。三团主体也有不同明暗，避免所有元素同样抢眼。

Pressure Unfurl 在主体 Geometry Nodes 中调整截面翻卷。主体材质的 Pressure Fracture 调整年轻阶段的破口，Pressure Support Value 调整辅助压力块的明暗。基底网格、节点和控制器仍可编辑；Complete Effect 保留这些私有造型，单层参数 JSON 仍重建普通 Burst。旧完整资产不会重建节点。

12 项局部 Blender 检查、原生重开、四种高清条件的三阶段原生像素比较、实际示例 ZIP 检查通过。预算逐帧审计为最高 860 顶点、四个显示对象、25 帧清空。旧完整资产载入后，第 5 帧所有 RGBA 通道与原生成器一致。接入最新主分支后，示例包再次生成，确保保留新刀光与压力核。

已实际读取多轮 Cycles 浅背景 3/5/9/13 帧、Eevee 浅背景完整序列的 13 张隔帧图，以及暗背景、AgX 近白远景、侧面的 2/5/14 帧。新形状从完整弯管变为较有方向的破碎喷流，主体与辅助块更可分辨；侧面较窄，远景的细流、压力弧和余烬仍弱。完整技能连段与最终 CI 尚需复核，不能宣布整体艺术验收。
