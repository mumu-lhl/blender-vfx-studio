# Impact Burst：拆分主体截面试作

[#124](https://github.com/mumu-lhl/blender-vfx-studio/issues/124) 处理主体像弯曲实心管的问题。原几何的六边形截面封闭，宽度与深度接近；朝向镜头的表面又铺较宽暖色，容易像几个完整物体。

已实际读取多轮 Cycles 浅背景 3/5/9/13 帧。只去掉封闭管的两面时，背面仍填满投影，改善有限；把它拆成开放薄面后，侧面过薄，未采用。当前候选使用两个分离的三角截面：主面较宽，辅助面较窄、稍晚出生、颜色较暗，同一顶点预算中留出真实间隙。

Pressure Unfurl 在主体 Geometry Nodes 中调整截面翻卷量；Pressure Support Value 在主体材质中调整辅助面明暗，不改变覆盖范围。基底网格可直接编辑。四条细喷射与两条辅助卷流保持原路径，普通 Burst 和旧完整资产不重建；完整效果保存私有节点，单层 JSON 不保存这些造型。

12 项局部 Blender 检查通过，新增检查覆盖翻卷控制对细流/辅助路径的隔离，以及辅助明暗改变颜色而不改变透明覆盖。当前仍是试作：部分形状像弯角，侧面较窄，不能根据检查通过宣布艺术改进。完整 Eevee、远景、原生重开及连续动画还需复核。

不增加发光、粒子或显示对象，Low 顶点预算保持原来的 824 上限。整体 #89 保持开放，不发布 0.22.3。
