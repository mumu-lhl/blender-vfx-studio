# Energy Charge：让外层能量流抵达核心

[#112](https://github.com/mumu-lhl/blender-vfx-studio/issues/112) 接续进流改进。实际图像中，核心下方仍像一层旋转裙边。检查原生节点发现，三条外层丝带默认转过 7.8 弧度，超过一整圈；高度从 -0.65 升到 +0.45，末端并没有抵达核心高度。它们更像绕场的装饰，削弱了向内汇聚的方向。

本轮将外层路径的默认转角改为 2.4 弧度，以三个不同的起始高度接近核心，末端高度归零。仍保留不等长、加速运动、流动色带和原来的三条路径；地面五条进流不变。实际顶点、对象、粒子和发光预算不增加，旧完整资产不重建。

另一个修正让核心同一截面的顶点一起转动和漂移。原来每个顶点按自己的高度取扭转角，修改宽度时连截面中心也会移动；现在先扣除截面偏移，再用共同中心计算扭转与轮廓位移。宽度调整引起的最大中心漂移由约 0.00342 降到浮点误差范围。正常镜头的变化较小，不能把这项行为修正当成显著艺术提升。

已实际读取 Cycles 13/31/42 的同镜头前后图。外层裙边减少，核心周围空隙更清楚，但核心自身仍有弯叶感。曾比较更圆的主体和更细的材质溶解，未得到足够明确的改善，因此没有纳入本轮。Eevee、浅背景、远景、侧面和连续变化仍需完成复核。

15 项真实 Blender 入门库测试通过，新增检查验证三条外层路径的末端接近核心、起点分布在不同高度，以及修改主体宽度不移动路径中心。原有零宽度、统一时间、保存载入和预算检查保留；测试不替代看图。整体艺术任务 #89 保持开放，0.22.3 不发布。

在 Outliner 展开 Energy Charge，选择外层 `VFX • Converging Vortex Ribbons` 的 Geometry Nodes。Spiral Turns 控制绕行角度，Intake Vertical Reach 控制起始高度的分散程度；设为 0 可比较平面流。核心的 Main Intake Guide Width 等宽度控制保持原用法。保存整个组合为 Complete Effect 可保留节点修改，通用参数 JSON 不保存私有造型。
