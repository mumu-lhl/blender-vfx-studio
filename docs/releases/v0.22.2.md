本预览版改进 Energy Charge 的汇聚方向、视觉主次和末段淡出。目标 Blender 5.2 LTS，优先 Eevee，同时支持 Cycles。

粒子现在从外围向中心汇聚，抵达中心后停止。一个地面环改为缓慢转动的倾斜轨道，另一个保留为低亮辅助层。球壳在前段逐渐显现，用深色主体和青色边缘形成焦点；浅背景也能看清主体。末段逐渐变暗，避免上一帧仍然明亮、下一帧突然消失；新资产的私有材质采用 Blended，减少 Eevee 低采样下的透明颗粒。

这些改动作用于实际入门库生成器。保持四层、LOW 质量、48 帧时长与原粒子槽位预算，没有提高发光强度。效果仍使用原生节点和驱动，保存后的 `.blend` 无需插件即可播放。普通 Emitter 和已有完整资产不重建；复用自定义节点与轨道驱动请保存完整效果，单层参数预设只保存参数。

安装请选择 `blender-vfx-studio-0.22.2.zip`，在 Preferences → Get Extensions → Install from Disk 中安装。`blender-vfx-studio-examples-0.22.2.zip` 是独立资产库，解压后添加到 Asset Libraries；它不是插件安装包。可用 `SHA256SUMS` 核对全部 ZIP 的完整性。

附带充能的 960×540 预览：Cycles 和 Eevee 暗/亮背景各九帧；文件名中的 `legacy` 仅表示恢复旧 Fade 和透明模式来检查突切，不是整个旧造型。发布流程运行三平台后台测试、安装/卸载、无插件重开与原生渲染对比；具体实图检查、重建命令及限制见 [充能记录](https://github.com/mumu-lhl/blender-vfx-studio/blob/v0.22.2/docs/CHARGE_VISUAL_REVIEW.md)。

本轮没有实时观看连续视频或验收真实角色蓄力动作。LOW 质量的多边形轮廓仍可见，亮背景细线和微粒仍偏弱；后续继续改进粒子形状、蓄力到释放的衔接和真实镜头表现。复杂骨架与跨平台 GUI 扩展继续暂缓。

另附 `blender-vfx-studio-handoff-review-0.22.2.zip`，保存实际检查的充能→挥斩→命中场景、34 张渲染图和记录；其中实际读取的范围为 Cycles 17 帧与 Eevee 亮背景 6 帧，未实时观看完整视频。解压后可直接打开原生 `.blend`，或使用附带的 `check_native.py` 复核；它不是插件安装包。

正式下载的全部 ZIP 校验值已复核；扩展与标签全新克隆构建逐字节一致，实际示例 ZIP 通过无插件重开。三平台标签检查与发布流程全部通过。尖形充能微粒属于后续候选，不包含在 0.22.2 中。

直接复核下载的检查包时，在解压目录运行：

```sh
blender -b --factory-startup --disable-autoexec --python-exit-code 1 cycles-dark/handoff.blend --python check_native.py
```

Eevee 场景位于 `blender_eevee-light/handoff.blend`；Linux 软件渲染可加 `LIBGL_ALWAYS_SOFTWARE=1 EGL_PLATFORM=surfaceless`。本次逐像素通过记录采用 Blender 5.2.2 和相同渲染环境。
