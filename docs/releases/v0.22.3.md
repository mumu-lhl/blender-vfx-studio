本预览版继续打磨 Energy Charge 的开场节奏与微粒形状，目标 Blender 5.2 LTS，优先 Eevee，同时兼容 Cycles。

圆点改为沿汇聚方向排列的低面数尖形微粒，暗尾渐变到青色前端，Size 仍整体缩放。两条蓄力环从相对的弧逐渐闭合，地面环先完成、轨道稍后；球壳保持视觉焦点，避免出生帧直接亮起完整双环。颜色、发光强度、层数与粒子预算不增加，每粒几何减少，旧完整资产和普通 Emitter / Ring 不重建。

修改实际入门库生成器，使用原生节点和简单驱动，不依赖逐帧 Python 或外部贴图。保存后的 `.blend` 无需插件播放。显现时长可在材质的 Draw Duration 节点中编辑，尖形比例可在几何节点的 Mote Proportions 中编辑；单层参数 JSON 不保存这些私有节点，复用编排请保存完整效果。

安装请选择 `blender-vfx-studio-0.22.3.zip`，在 Preferences → Get Extensions → Install from Disk 中安装。examples ZIP 是独立资产库，解压后添加到 Asset Libraries；SHA256SUMS 用于核对 ZIP 完整性。

附带 Cycles / Eevee 暗、亮背景的 960×540 充能预览，包含第 1、4、7 帧开场和峰值、退场。legacy 文件只恢复旧 Fade 与透明模式，不是完整旧造型。节点原因、实际看图范围和重建命令见仓库的 [充能记录](https://github.com/mumu-lhl/blender-vfx-studio/blob/v0.22.3/docs/CHARGE_VISUAL_REVIEW.md)。

本轮实际读取静帧，未实时观看完整动画；真实角色动作、更多镜头和集成显卡帧率仍待检查。Low 质量的多边形轮廓可见，亮背景初始细弧和末段微粒仍弱，后续继续改进完整战斗镜头中的可读性。
