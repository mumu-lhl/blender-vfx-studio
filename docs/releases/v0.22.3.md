这是一版仍在进行艺术迭代的预览版。充能、刀光和命中效果的真实原生资产都有造型、材质与运动改进；技术测试通过不代表整体商业级品质或真实角色镜头已经验收。

Energy Charge 从球壳与细环改为多瓣电浆核心、内部亮核、三维盘卷流带、非对称地面收束形状和弯曲汇聚粒子。统一进度控制起势、加速收束、压缩和快速释放，白核先退为青蓝再裂解，减少与挥斩抢焦点。默认粒子槽减少至 12，仍为四个显示对象，Low 顶点预算上限为 900。

Arc Slash 版本 3 加入前端钩形、内侧缺口、深度弯曲和逐渐分离的残影，材质使用紫色亮暗分面与分段消散。新增 Contour、Bank、Wake Spread，Low 仍为 594 顶点；默认发光降低。版本 1/2 的节点和参数预设保持原行为。

Impact Burst 由整圈宽片改为七条带横截面的弯曲喷流，配紧凑短闪、分段压力弧和延迟余烬。各方向错开弯曲、收缩并向外分离，命中中心更早露出；暖色侵蚀边缘先亮起再冷却。主体材质的深色轮廓改善浅背景边界，Rim Contrast / Rim Width 可编辑。仍为四个显示对象，Low 最高约 888 顶点，短闪和主体的发光低于旧版，没有额外辉光或粒子槽。

所有造型、材质和驱动保存在 Blender 原生数据中，无逐帧 Python、外部纹理或缓存。普通模块及旧完整资产不重建。复杂编排请用 Save Complete Effect 保存；单层参数 JSON 不能还原私有造型。侧栏只显示编排实际使用的参数，其他控制可在原生节点中编辑。

实际读取了多阶段高清 PNG、暗/亮背景、远景及战斗衔接，并进行视频抽帧检查；没有实时观看视频、真实角色或实际低配置视口验收。主喷流仍有粗硬感，浅色远景的细余烬偏弱。具体范围和限制见仓库的充能、刀光、Impact 及轮廓检查记录，整体艺术目标 #89 继续开放。
