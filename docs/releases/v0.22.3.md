# 开发预览说明（未发布）

Blender VFX Studio 用 Blender 原生网格、材质、Geometry Nodes 与动画制作可编辑特效，目标 Blender 5.2 LTS，优先 Eevee，兼容 Cycles。项目尚未正式分发。

## 当前内容

- 八套完整资产：Energy Charge、Arc Slash、Impact Burst、Lightning Strike、Dust Impact、Stylized Fire、Character Dash Echoes 和 Calligraphic Magic Circle。
- 独立控制器与统一时间参数，可修改尺寸、颜色、运动和各层关系；支持组合、Ungroup All、复制、删除和完整 `.blend` 保存。
- 可采样武器轨迹、捕获角色姿态，生成不依赖源角色持续运行的原生效果。
- 新五套各有三种质量档，按镜头需求选择细节和开销；顶点数不能代替实际性能测量。

## 验证范围与限制

已建立真实 Blender 后台、保存重开和原生像素检查，并实际读取高清阶段图及隔帧动画。它们不代表实时视频观看、设备视口帧率或商业成片品质已验收。远景细节、角色动作中的焦点与衔接仍在打磨，具体范围见入门指南和各效果检查记录。首次正式分发前仍需完成必要视觉与使用验证。
