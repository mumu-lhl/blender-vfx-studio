# Energy Charge：压缩中心的轮廓

[#120](https://github.com/mumu-lhl/blender-vfx-studio/issues/120) 继续处理蓄满后焦点细碎、浅背景白核不清楚的问题。原来的内核是 54 顶点的椭圆，表面大范围混入白色；外部收紧后，中心缺少可辨认的蓝色体块。

试作过更大的扭曲椭圆、深凹轮廓和平面着色，并实际读取关键帧。前两种仍像球体，平面着色又变成硬折面，均不选用。当前候选将同样的 54 顶点重新分给三段不等的闭合火舌，保留实际间隙；积蓄与释放继续读取原来的统一时间，不添加对象或粒子。Low 最高 894 顶点预算不变。

材质用表面朝向和火舌纵向位置限制白色区域，外围保留蓝色与深边，避免整个中心变成白点。Nucleus White Threshold 调整白色面的范围，Nucleus Blue Depth 调整蓝色底色；两者都在核心材质中。原有 Nucleus Seed Size / Nucleus Stored Size 调整积蓄尺寸，Release Pinch / Release Stretch 调整释放形变。基底火舌可直接编辑原生网格，完整效果保存这些修改，通用参数 JSON 不保存私有造型。

已实际读取 Cycles 暗/浅背景 13/31/37/43 帧，并比较同引擎、同镜头的浅背景 AgX 远景。中心由白椭圆变为有间隙的蓝白束，近景更可辨认；远景仍小，不能宣布远景问题或整体艺术目标已解决。18 项局部 Blender 检查通过，新增颜色控制的像素检查确认它不改变透明覆盖；完整 Eevee、侧面、无插件重开与连段仍需验证。

这是候选，不是艺术验收结果。#89 保持开放，不发布 0.22.3；没有实时播放、真实角色或设备帧率验收。
