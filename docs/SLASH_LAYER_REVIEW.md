# Arc Slash：前端体积与分层退场

[#102](https://github.com/mumu-lhl/blender-vfx-studio/issues/102) 继续处理刀光偏规则、残影层次不足的问题。本分支新建刀光使用资产版本 4；版本 1/2/3 仍可重建，载入旧完整资产不会替换节点。整体艺术目标 #89 继续开放，0.22.3 未发布。

## 从画面定位节点问题

在充能重做后的真实连段中，29–30 帧的刀光仍是规则宽片，31–33 帧退成密集细丝。原宽度以 `sin(πu)^Taper` 为基础，Head Bias 只乘一个线性权重，峰值仍偏中段；两条残弧仅延迟出现，揭示、侵蚀和碎片都使用主刀面的同一个进度。

版本 4 用 Head Bias 改变沿弧坐标，再计算宽度。默认宽度峰值移向前端；设为 0 时恢复对称收尖。Contour 控制三个位置、宽度、深度不等的内缘缺口，缺口深度和外轮廓随时间变化。Bank 保留刀面深度，不增加网格。

两条残弧分别延迟出生，并使用自己的局部年龄：从总进度中减去出生延迟，再按各自较长的寿命缩放。几何揭示、扫掠、宽度和材质消散都使用这个年龄，因此它们会在亮刃退出后继续分段漂移。残弧宽度、视觉权重也有差别，Afterimage 仍可将它们完全关闭。

首轮高清图中，残影确实晚于主体，但衰减仍像被梳开的细线。原因是材质横向噪声频率高，再被硬裁切，产生过多窄碎丝。随后降低噪声与笔触频率，让纹理沿挥斩方向滚动，改成较少、较宽的碎段；主体内部增加受 Streaks 控制的彩色流带，白色仍集中在前端窄刃。发光强度不增加。

浅灰后段和近白远景仍显示残弧过弱。分别关闭侵蚀、碎片与条带遮罩，以及只保护宽头的原生节点实验，都没有明显恢复所需层次，因此这些实验没有写入生成器。随后把两条残弧的宽度分别调为主体的 38% 和 28%，默认 Afterimage 调为 0.42；实际透明权重仍低于主体，并且不同。已重读 Eevee 的 5/9/11/13 帧：残弧更明显，细尾仍弱。版本 3 的参数表单独保留，默认值与像素对照不变。

版本 4 的负 Spin 同时翻转弧方向，使宽头与残弧跟随反向扫掠；Spin=0 保留正向静止造型。几何镜像测试覆盖正负方向，尚未据此声称完成反向动画的视觉验收。

## 当前复核

已实际读取 Cycles 同镜头版本 3 峰值及两轮版本 4 的出现、峰值、衰减图，再读取最新 Eevee 浅灰背景的 2、3、5、7、9、11 帧。前端体积更集中，尾部更细；衰减由密集细丝变为较宽笔触，暗残弧保留得更久。远景、后段剩余帧与充能到命中的新衔接仍需复核，不能据此宣布艺术验收或实时播放通过。

当前 15 项 Blender 刀光测试、11 项参数预设测试通过。新测试核对 Head Bias 的前后体积分配、主刀面消失后残弧仍可见、关闭 Afterimage 后残弧清空、正负扫掠方向，以及重定时后的真实像素一致。保存后，版本 3 和版本 4 的几何与低分辨率三阶段像素均通过无插件重开。版本 3 另经明确版本重建，三张 960×540 对照图与修改前逐像素一致。

Low 仍为 594 顶点、一个显示对象、一个材质。没有外部纹理、缓存或帧处理器；颜色、尺寸、时间和所有已有控制仍有效，完整节点可用 Save Complete Effect 保存。

用 `tools/slash_preview.py` 按 [既有复现命令](VISUAL_REVIEW.md#复现与验证) 生成实际图；`--asset-version 3` 保留旧版对照，`--asset-version 4` 明确选择候选。按生成的 settings JSON 使用图片，避免把目录中的旧图当成当前结果。
