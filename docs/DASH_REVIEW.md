# Character Dash Echoes：姿态残影与安全捕获

这套效果将角色在几个帧位的求值网格保存为独立残影，依次出现并淡去。身体较淡，内缘偏青，外缘较暗；较旧姿态不抢当前角色的视觉权重。首轮浅背景图里残影太淡，修正版在真实材质中增加明确的内外轮廓，并调整淡去曲线。修改前后的同帧图均已读取。

## 使用自己的角色

1. 在 Object Mode 选中 Mesh 或 Armature，点击 **Capture Dash Echoes**。
2. 设置首尾帧与每个姿态的 Echo Tail。Low / Medium / High 分别保存两／三／四个姿态，保留原网格形状。
3. 编辑组合时间、位置，或分别修改各层颜色、透明度、Fresnel 边缘和侵蚀；用 **Save Complete Effect** 保存完整姿态。

采样跨度需能被姿态间隔数整除，例如三姿态使用 1、7、13 帧。源网格、材质、形态键和动画不改动，操作后恢复原帧及子帧；结果只记录源名称，不保留源对象引用。源动画改变后需明确重新捕获。原生参数 JSON 不包含姿态网格。一百万存储顶点的保护限制用于控制创建时分配，不代表性能上限。

内置示例取自仓库固定版本的 CC0 KayKit 角色：原生 Running_A 动作配合明确设置的根位移，从 X=-2 冲到 X=1.4。在 6、12、18 帧采样，独立完整资产从第 1 帧开始，持续 30 帧；三档质量保持相同时序。默认三个姿态保留 14,463 顶点，未为了套用旧几何预算而删掉角色轮廓。

## 成本与取舍

保留多份角色网格及重叠透明面有实际代价。测试使用同一场景，只排除 VFX 集合；CPU 求值各测量 27 个预热后样本，渲染先预热两次再交替比较三个帧位。

本地为 CPU 配额 2、两线程、Mesa 25.0.7 llvmpipe。求值中位数由 0.549 ms 变为 0.799 ms；第 12、19、27 帧渲染的无／有 VFX 耗时分别为 14.841/58.100、14.433/76.565、14.453/61.111 秒。冻结网格的求值较便宜，透明材质渲染明显更贵；不能用顶点数判断整体成本。

这些是后台求值和软件渲染墙钟时间，**不是视口 FPS**，三个配对样本也不足以报告稳定渲染 p95。需要更少开销时可选 Low 或减少重叠；镜头需要更完整轨迹时可以保留更多姿态，不把最低成本作为统一要求。
