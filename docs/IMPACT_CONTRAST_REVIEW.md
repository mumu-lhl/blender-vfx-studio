# Impact 的浅背景轮廓

[#96](https://github.com/mumu-lhl/blender-vfx-studio/issues/96) 接续原生喷流造型。实际读取 Eevee / AgX 的近白远景图后，主喷流虽然可辨，亮橙色表面与背景的边界仍偏淡。第一版很窄的暗边几乎没有改善，因此改用较宽的平滑过渡。相同相机下，主喷流上缘现在能保留更清楚的深橙边界；细余烬依然很弱，本次没有增加粒子或扩大它们。

材质读取表面法线与视线方向，计算接近侧面的区域，再将这些区域混入由控制器颜色生成的深色。取绝对值让正反面一致；视线由原生着色节点提供，不引用某一个相机对象。颜色变深，但透明遮罩、几何、运动与生命周期保持原样。仍为四个显示对象、四个材质，Low 最多约 888 顶点，没有额外网格、纹理或辉光。

在主体材质中，Rim Contrast 控制暗边强度，设为 0 可关闭；Rim Width 的 From Max 越高，过渡区域越宽。默认强度为 0.85，过渡范围为 0.3–0.85。颜色仍由控制器驱动，暗边跟随主色变化。已有完整资产不会自动重建或添加暗边，保存手动修改请继续使用 Save Complete Effect。

## 当前验证范围

9 项 Blender 测试及无插件重开通过。新增测试检查暗边确实改变颜色、透明覆盖逐像素不变、不会将测试镜头中的大部分主体压黑，并验证绿色主色仍可使用。Cycles 默认镜头、Eevee / AgX 近白远景的三阶段高清原生重开逐通道一致，25 帧清空。测试不代替实际看图。

实际读取了 Cycles 默认镜头三阶段及正、侧面峰值，Eevee 浅灰背景与近白远景三阶段，以及暗背景的 3、5、7、9 帧。暗背景和低角度仍保留亮色主体与侵蚀边缘。武器/靶标衔接的 33、37 帧也已查看，31/33 帧原生重开一致，60 帧清空。主喷流仍有粗硬感，细余烬的远景可读性没有解决，不据此宣称整体艺术验收完成。此轮使用 PNG 抽帧检查，没有实时观看新视频、真实角色或低配置视口测量。
