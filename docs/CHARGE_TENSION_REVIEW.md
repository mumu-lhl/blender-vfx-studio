# Energy Charge：积蓄后的压缩与释放

[#131](https://github.com/mumu-lhl/blender-vfx-studio/issues/131) 继续处理内核的形态节奏。实际高清图与完整连段中，中心虽逐渐长大，但积蓄时仍像竖向火舌，外围碎片更显眼。原生成器已有尺寸增长与释放拉伸，缺少积蓄阶段独立的压缩形变。

新形变在原有三段内核上逐渐降低高度，并扩展横截面补偿体积。它从现有 Compression Builds 读取统一进度；释放窗口中解除压缩，接上原来的收束拉长。外围路径、材质与 Release Stretch 默认值保持不变，没有增加发光、纹理、顶点、粒子或对象。

选择 Charge • Compressed Core 下的网格，在 Geometry Nodes 调整 Nucleus Compression；0 关闭新增形变，默认 0.6，内部限制为 0–0.85，避免截面翻转。Nucleus Seed Size / Nucleus Stored Size 决定初始和蓄满大小，Release Pinch / Release Stretch 决定释放形态。节点、驱动器和网格随 Complete Effect 保存，已有完整资产不重建。

19 项局部 Blender 检查通过。新增检查确认压缩只改变内核、形变前后长宽高的乘积不变，早期与释放后不受影响；速度加倍后仍得到对应形态。逐帧审计为最高 894 顶点、四个显示对象、第 49 帧清空。四种高清条件均做了 4/7/22/37/42/43/48 帧无插件重开，全部 RGBA 通道一致：Cycles 浅背景，以及 Eevee 浅背景、暗背景、近白远景 AgX。实际示例 ZIP 通过检查，包内蓄力资产再以高清渲染 13/37/43 帧，与直接生成完全一致；旧完整资产的 13/37 帧也与旧渲染完全一致。

已核对主分支基线与冻结候选的源码摘要，实际读取同镜头 Cycles 和 Eevee 对照。Eevee 浅背景全部 30 个阶段帧、暗背景 13/31/37/42/43/48 帧、远景 31/37/43 帧，以及 Cycles 侧面和俯视 13/31/43 帧均已查看，另读取侧面峰值与实际资产高清图。积蓄到释放的轮廓变化更明确；远景中心仍小，俯视下竖向释放仍弱，外围碎片的主次也需要继续处理。
