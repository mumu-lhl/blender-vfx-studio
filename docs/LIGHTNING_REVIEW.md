# Lightning Strike：完整资产与角色检查

Lightning Strike 是第四套完整入门效果，与原有充能、刀光和命中爆发有不同用途。它在 18 帧内完成一次落雷和两次逐渐减弱的复击，包含分支电弧、接触短闪、火花和地面余波。28 帧的角色测试镜头保留后续受击和恢复动作。资产不包含测试角色，也不需要插件持续运行、外部贴图或模拟缓存。

主干由不等长折线和连通分支构成，交叉丝带形成白芯、蓝色主体和深色边界。控制器可修改范围、线宽、噪声、颜色、侵蚀与时间；主层 Geometry Nodes 中的 Bolt Length 和 Branch Reach 分别调整高度与分支伸展。消退阶段同步收细并降低光量，避免留下粗黑线。完整私有节点请用 Save Complete Effect 保存，参数 JSON 只会重建基础模块。

默认 Medium；Low 减少折线、分支和火花，High 增加这些细节。三档均有单独渲染的 Asset Browser 预览，是一种效果的三个质量版本。开发示例包因此包含四种效果、六个 `.blend` 文件。

## 实际检查范围

功能源码为 `252a5282329839d42bce279c0fe024d5c2db44d2`，之后合入 main 的文档不改变生成器。[PR #144](https://github.com/mumu-lhl/blender-vfx-studio/pull/144) 的 [Actions 运行](https://github.com/mumu-lhl/blender-vfx-studio/actions/runs/40454784154) 提供 `lightning-strike-review` 附件。附件 SHA-256 为 `5902f860a96a166bcc50c2b7f9f7af9e284fb349dbf6c50b15abd87fdbd912bd`，下载后已核对压缩包、源码、MP4 和解码帧记录。

本地与 CI 均渲染完整 1–28 帧、24 fps、960×540 的 Eevee 镜头，16 samples、AgX、无辉光。已实际读取两者全部 14 张视频隔帧图，以及暗背景和浅背景远景各十个阶段图；另读取高清峰值、末次复击和消退阶段。主干在近景与远景中仍可辨认，分支比主干细，三次放电逐次减弱，第 19 帧清空。细枝和接触火花在远景中较弱，脚边短闪也会受角色遮挡。这是当前可用资产的限制，不代表整套战斗镜头达到成熟商业作品的艺术品质。

这是视频解码静帧检查，**没有观看实时 24 fps 连续播放**。测试角色是 CC0 KayKit 低多边形角色，不等同于正式二次元角色验收。

无插件新进程按 12、3、8 的顺序跳帧，高清像素与源图一致，第 19 帧无效果几何，正常退出。五项闪电行为检查覆盖相对开始时间、三次脉冲、独立参数、质量差异和复制／删除安全性；20 项示例检查与六文件实际示例 ZIP 的原生重开也通过。三档嵌入缩略图已读取，不能代替高清检查。

## 实测成本

本地为 CPU 配额 2、Blender 两线程、Mesa 25.0.7 llvmpipe；CI 使用 Ubuntu 软件 Eevee、Mesa 25.2.8 llvmpipe，同样两线程。比较同一保存场景，只排除 VFX 集合，角色、相机、灯光与设置相同。求值丢弃三轮预热后，每种状态测量 27 个样本；渲染先预热两次，再交替比较三个相同帧。

| 测量 | 无 VFX | 有 VFX |
| --- | ---: | ---: |
| 本地求值中位数 | 0.829 ms | 4.315 ms |
| 本地求值 p95 | 0.983 ms | 4.477 ms |
| CI 求值中位数 | 0.359 ms | 2.247 ms |
| CI 第 3 帧渲染 | 9.439 s | 9.947 s |
| CI 第 8 帧渲染 | 9.438 s | 10.002 s |
| CI 第 12 帧渲染 | 9.544 s | 10.298 s |

本地三个配对渲染分别为 12.073/12.883、13.264/13.460、13.083/14.990 秒（无／有 VFX）。首次材质编译会明显更慢；这些是后台求值和渲染墙钟时间，不能换算为视口 FPS。三个配对样本也不足以报告稳定渲染 p95。
