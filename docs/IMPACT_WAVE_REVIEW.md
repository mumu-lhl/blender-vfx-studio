# Impact Burst：有截面的压力弧

[#128](https://github.com/mumu-lhl/blender-vfx-studio/issues/128) 接续 #124 的压力体积。旧波面只有内外两排顶点，从侧面看接近一条线；均匀正弦切口与快速 UV 平移也让碎口缺少连续的移动关系。

新波面增加中间一排，形成可调整的隆起截面。Low 从 48 段、两排改为 32 段、三排，仍为 96 顶点；Medium 和 High 分别为 64、128 段，每段三点。三个不同长度、宽度的弧段共用 Geometry Nodes 与材质中的分段轮廓，宽度向两端收尖。颜色分为主体橙红与较暗边缘，保留原发光强度。

第一版渲染过细，浅色远景比旧版更难辨认，因此没有采用其默认值。第二版把真实波面宽度从 0.18 调到 0.30，提高截面，并降低初始破碎阈值。材质的噪声平移改由原生进度驱动，默认全寿命移动 0.35 UV，避免旧设置快速切换碎口；没有增加噪声纹理或对象。

节点中的 Pressure Crest Height 调整截面高度，Pressure Crest Edge Contrast 调整暗边，Pressure Flow Travel 调整纹理行进距离。控制器的 Width、Dissolve、Fade 与组时间继续生效；Width 为零时波面收拢，Height 为零时回到平面。改动仅用于新建 Impact Burst，普通 Shockwave 与已有完整资产不重建。

当前已实际查看相同镜头的 Cycles 浅背景前后图，以及第一版 Eevee 浅色远景采样；第一版的可读性退步已记录。第二版的 14 项局部 Blender 检查通过，并已查看 Eevee 近白远景 AgX 的 2/3/5/7/9/14 帧：压力弧比第一版更连贯、更易辨认，末段细屑仍弱。Eevee 全序列、暗背景、侧面、原生重开与完整连段仍在验证，尚未宣布视觉验收。整体 #89 保持开放，不发布 0.22.3；未进行实时播放、真实角色或设备帧率验收。
